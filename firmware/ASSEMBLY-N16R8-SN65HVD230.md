# Сборка OBD-шлюза: ESP32-S3 N16R8 + SN65HVD230

Подробная инструкция для варианта **встроенный CAN (TWAI) + трансивер SN65HVD230**.  
Прошивка: [`arduino/EwdObdGatewayTwai`](./arduino/EwdObdGatewayTwai) (Arduino IDE) или PlatformIO env `esp32-s3-n16r8-twai`.

---

## 1. Что купить

| Позиция | Зачем |
|---------|--------|
| Плата **ESP32-S3 N16R8** (DevKitC-1 / аналог, 16 MB flash + 8 MB PSRAM) | MCU + Wi‑Fi SoftAP |
| Модуль **SN65HVD230** (3.3 V CAN transceiver breakout) | Уровень CAN-H/L к машине |
| Кабель **OBD-II** (female) или разъём + провода | Пины 6 / 14 / 4 / 16 / 5 |
| DC-DC **12 V → 5 V** (или 12→3.3 V с запасом по току) | Питание от авто (опционально; для стола — USB) |
| Провода Dupont, макетка / пайка | Сборка |
| (Желательно) предохранитель 1–2 A на +12 V | Защита |

Не берите модули «5 V only» без согласования уровней с S3 (логика 3.3 V). SN65HVD230 как раз 3.3 V.

---

## 2. Распиновка (зафиксировано в прошивке)

| SN65HVD230 | ESP32-S3 | Примечание |
|------------|----------|------------|
| **3V3** / VCC | **3V3** | Не на 5 V |
| **GND** | **GND** | Общая земля с OBD pin 4/5 |
| **CTX** (TXD) | **GPIO 17** (TWAI TX) | Выход контроллера → вход трансивера |
| **CRX** (RXD) | **GPIO 18** (TWAI RX) | Выход трансивера → вход контроллера |
| **CANH** | OBD **пин 6** | HS-CAN High |
| **CANL** | OBD **пин 14** | HS-CAN Low |

Типичный вид модуля (названия шелкографии могут чуть отличаться: `TX`/`RX` = CTX/CRX):

```text
        ESP32-S3 N16R8              SN65HVD230              OBD-II
        --------------              ----------              ------
        3V3 ----------------------> 3V3
        GND ----------------------> GND ------------------> pin 4 (chassis GND)
                                                          pin 5 (signal GND) — тоже на общий GND
        GPIO17 (TWAI TX) ---------> CTX / TXD
        GPIO18 (TWAI RX) <--------- CRX / RXD
                                    CANH -----------------> pin 6
                                    CANL -----------------> pin 14
        USB-C (прошивка/лог)       (RS: см. ниже)
        5V от buck (опц.) <-------- +12V OBD pin 16 через DC-DC
```

### Пин RS на модуле SN65HVD230

- Часто выведен как **RS** / **S**.
- Для высокой скорости (500 kbit): **RS → GND** (через 0 Ω или перемычку), либо по даташиту модуля «high-speed».
- Если модуль уже с резистором на GND — ничего не трогайте.
- Не оставляйте RS «в воздухе», если в инструкции модуля сказано подтянуть.

### Терминатор 120 Ω

На шине авто уже есть оконечная нагрузка. На коротком кабеле адаптера:

- **По умолчанию:** дополнительный 120 Ω **не** ставить.
- Если на столе (два устройства без машины) — нужен 120 Ω между CANH–CANL на макете.
- Некоторые модули имеют джампер `120R` — для машины лучше **снять**.

### Питание

| Режим | Как |
|-------|-----|
| Стол / отладка | Только USB-C ноутбука; CAN к машине при **включённом зажигании**, общая GND обязательна |
| В машине | OBD pin 16 (+12 V) → buck 5 V → `5V` платы **или** 3.3 V выход buck → `3V3` (не подавать 5 V на 3V3!) |

**Важно:** при питании от USB и работе с CAN машины соедините **GND платы с OBD pin 4/5**, иначе «плавающая» земля и ошибки шины.

## 3. Безопасность

1. Сборку проверяйте **без** подключения к авто (звонок / мультиметр на коротыши 3V3–GND, CANH–CANL).
2. Первое подключение к OBD — зажигание ON, двигатель можно не заводить.
3. Не замыкайте CANH/CANL на +12 V.
4. Прошивка по умолчанию **только чтение**; Clear DTC — только с двойным confirm в UI.
5. Не используйте на ходу как «игрушку» — только диагностика на стоянке.

## 4. Прошивка (Arduino IDE)

### 4.1. Подготовка IDE

1. Установите [Arduino IDE 2.x](https://www.arduino.cc/en/software).
2. **File → Preferences → Additional boards manager URLs:**
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
3. **Boards Manager** → установите **esp32** by Espressif (3.x).
4. **Library Manager** → установите только:
   - `ArduinoJson` (Benoit Blanchon) **v7.x**  
   (WebSockets больше не нужны — API только HTTP.)

### 4.2. Открыть скетч

Папка репозитория:

```text
firmware/arduino/EwdObdGatewayTwai/EwdObdGatewayTwai.ino
```

Откройте `.ino` — рядом должны лежать `.cpp` / `.h` (Arduino подбирает их сам).

### 4.3. Настройки платы

| Параметр | Значение |
|----------|----------|
| Board | **ESP32S3 Dev Module** (или ваша N16R8) |
| USB CDC On Boot | **Enabled** |
| Flash Size | **16MB (128Mb)** |
| PSRAM | **OPI PSRAM** / Enabled (если есть в меню) |
| Partition Scheme | Default 16MB или Huge APP |
| Upload Speed | 921600 (при ошибках — 115200) |
| Port | COMx платы |

### 4.4. Заливка

1. Подключите USB-C.
2. **Sketch → Upload**.
3. Если не входит в загрузчик: зажмите **BOOT**, нажмите **RESET**, отпустите RESET, затем BOOT; повторите Upload.
4. **Tools → Serial Monitor**, 115200 бод.

Ожидаемый лог:

```text
=== EWD OBD Gateway (N16R8) ===
TWAI 500k OK
SoftAP EWD-OBD-Gateway  IP 192.168.4.1
Smoke PID05: ... (или no response без машины)
```

## 6. Проверка без сайта

1. Телефон → Wi‑Fi **EWD-OBD-Gateway** / пароль **volvo-obd**.
2. Браузер: `http://192.168.4.1/health` → `{"ok":true,...}`.
3. С машиной: `POST` на `http://192.168.4.1/scan` (или откройте сайт → «Скан с адаптера» → вставка JSON с `GET /scan`).

Smoke без UDS: в Serial должна появиться температура ОЖ (PID 05), если зажигание ON и HS-CAN жив.

---

## 7. Типовые проблемы

| Симптом | Что проверить |
|---------|----------------|
| `TWAI … FAIL` / нет OK | GPIO 17/18, CTX/CRX не перепутаны местами |
| Нет ответа PID05 | Зажигание, пины 6/14, общая GND, 500 kbit |
| Upload failed | BOOT/RESET, кабель data (не charge-only), драйвер USB |
| SoftAP нет | Питание слабое; смотрите Serial |
| HTTPS сайт не видит шлюз | Mixed content — вставьте JSON с `/scan` вручную |
| Ошибки шины / error frames | Лишний 120 Ω; плохой контакт; перепутан H/L |

---

## 8. Смена пинов

В скетче: `config.h` → `OBD_TWAI_TX` / `OBD_TWAI_RX`.  
После смены пересоберите и прошейте заново.

Пины **6–11** на части DevKit заняты flash/PSRAM — **не** используйте их для TWAI без схемы платы.
